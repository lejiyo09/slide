# SlideLab

설치 없이 브라우저에서 동작하는 **웹 기반 프레젠테이션 편집기**입니다.
Microsoft PowerPoint 데스크톱의 작업 방식(리본, 슬라이드 탐색기, 캔버스, 서식 창)을 참고해 독자적으로 구현하며,
서버 없이 핵심 편집 기능이 동작하고 작업 내용은 브라우저의 IndexedDB에 자동 저장됩니다. PWA로 설치하면 오프라인에서도 실행됩니다.

> Microsoft 365의 유료 기능을 해제하는 프로그램이 아니라, 대응 기능을 자체 구현한 독립 프로그램입니다.

## 실행

```bash
npm install
npm run dev          # 개발 서버 (http://localhost:5173)
npm run build        # 타입 검사 + 정적 빌드 (dist/)
npm test             # 단위 테스트 (Vitest)
npm run test:e2e     # 브라우저 E2E (빌드 후 `npx vite preview --port 4173` 실행 상태에서)
npm run verify:pptx  # 내보낸 PPTX를 python-pptx/LibreOffice로 검증
```

GitHub Codespaces에서도 동일하게 실행됩니다. `main`에 push하면 `.github/workflows/deploy.yml`이 테스트·빌드 후 GitHub Pages에 배포합니다
(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 합니다). `base: './'`로 빌드하므로 하위 경로에서도 동작합니다.

### 구현된 기능
- **슬라이드**: 추가(레이아웃 6종), 복제, 삭제, 드래그/단축키로 순서 변경, 다중 선택(Ctrl/Shift), 숨기기, 구역(추가·이름 변경·제거·접기), 축소판, 여러 슬라이드 보기, 복사/붙여넣기
- **캔버스**: 선택/다중 선택/영역 선택, 이동(Shift 축 고정, Ctrl+드래그 복제), 회전된 개체 크기 조절(그림은 비율 유지), 회전(Shift 15°), 선 끝점 편집, 스마트 안내선·개체 맞춤(Alt로 해제), 눈금선, 확대/축소(Ctrl+휠, 창에 맞춤), 컨텍스트 메뉴, 파일 드래그 앤 드롭, 이미지 붙여넣기
- **텍스트**: 서식 있는 텍스트 편집(문단·런 단위), 글꼴, 크기, 굵게/기울임/밑줄/취소선, 글자 색, 형광펜, 맞춤, 줄 간격, 글머리 기호/번호, 수준(Tab), 텍스트 방향, 세로 맞춤, 여백, 자동 크기 조정, 개체 틀 안내 문구
- **도형**: 20종 프리셋, 채우기(없음/단색/그라데이션/투명도), 윤곽선(색/두께/대시), 도형 안 텍스트, 선·화살표(머리 모양)
- **이미지**: 업로드(PNG/JPG/GIF/WebP/SVG), 스크린샷 캡처, 크기 조절, 자르기(핸들/수치), 회전, 대칭, 투명도, 그림 바꾸기, 원래대로
- **배열**: 맞춤 6종 + 간격 동일하게, 순서 4종, 그룹/그룹 해제, 서식 복사(Ctrl+Shift+C/V)
- **디자인**: 테마 5종, 슬라이드 배경, 모두 적용, 16:9 / 4:3 / 사용자 지정 크기
- **저장**: IndexedDB 자동 저장, 프로젝트 목록 열기/삭제, `.slidelab`(JSON) 가져오기/내보내기, 버전 저장·복원
- **PPTX 내보내기**: 텍스트·문단 서식, 도형, 선/화살표, 이미지(자르기 반영), 회전/대칭, 투명도, 배경(그라데이션은 이미지로), 노트, 숨김 슬라이드, 구역, 슬라이드 크기. 변환 손실은 내보내기 화면에 **호환성 알림**으로 표시
- **PPTX 가져오기**: 파일 › 열기, 창에 끌어다 놓기, 설치된 앱에서 .pptx 바로 열기. 이미지로 변환하지 않고 편집 가능한 개체로 해석하며, 결과를 "호환성 알림"으로 보고
- **슬라이드 쇼**: 처음부터/현재부터, 전체 화면, 키보드(→ ← Space PgUp/Dn Home End, 번호+Enter), 검은/흰 화면(B/W), 숨김 슬라이드 건너뛰기, 발표자 보기·펜·레이저·확대 등 (아래 "발표 도구")
- **PWA**: 매니페스트, 서비스 워커(오프라인 실행), 설치 버튼, 새 버전 알림, `.pptx`/`.slidelab` 파일 핸들러 선언
- **기타**: 다크 모드, 상황별 탭(도형 서식/그림 서식), 키보드 단축키

## AI 도우미 (12단계)

홈 탭 › **AI 도우미**(디자인 탭 › 디자인 아이디어)로 오른쪽 창을 엽니다. 모든 결과는 문서에 바로 들어가며 **실행 취소 한 번**으로 되돌릴 수 있습니다.

- **제공자 구조** (`src/services/ai/`): 편집기는 `AIProvider` 인터페이스만 사용하고 제공자는 설정에서 바꿉니다.
  - **기본 엔진(오프라인, 키 없음)**: 문서 구조 분석·추출 요약·발표 유형별 구성 틀·템플릿 대본·규칙 기반 추천. 새 사실을 지어내지 않으므로 주제만으로 만든 슬라이드는 "작성 안내" 수준의 초안입니다.
  - **GPT — 사이트 중계 서버 (권장, 배포용)**: OpenAI 키는 Cloudflare Worker 중계 서버(`proxy/`)에만 두고, 앱은 중계 서버 주소와 접근 코드만 사용합니다.
    키는 GitHub Secrets에 입력하면 `.github/workflows/ai-proxy.yml`이 Worker 비밀 값으로 배포하므로 공개 사이트 파일에는 들어가지 않습니다. 설치 방법: [`proxy/README.md`](proxy/README.md)
  - **OpenAI (GPT)**: 본인의 OpenAI API 키로 `api.openai.com/v1/chat/completions`를 브라우저에서 직접 호출(JSON 스키마 `strict` 응답). 이미지 생성(`/images/generations`, 기본 `gpt-image-1`)도 같은 키로 사용.
  - **Claude (Anthropic)**: 공식 `@anthropic-ai/sdk`(Apache-2.0, 사용할 때만 지연 로딩)로 구조화 출력 + 스트리밍, 안전 정책 거절 시 서버 측 대체 모델(`fallbacks: "default"`), PDF 문서 직접 읽기.
  - **OpenAI 호환 엔드포인트**: 로컬 Ollama·LM Studio 등 같은 형식의 서버 (JSON 스키마를 거부하면 지시문에 스키마를 넣어 재시도).
- **만들기**: 주제·설명으로 / 목차 먼저(목차를 고친 뒤 생성) / 문서에서(.txt, .md, .docx — Claude는 .pdf도). 슬라이드 수·청중·발표자 노트, 바꾸기/뒤에 추가. 문서의 레이아웃 개체 틀을 써서 테마·마스터 디자인을 그대로 따름
- **다듬기**: 선택한 개체/현재 슬라이드 요약(개체 바꾸기·새 슬라이드·노트·텍스트 상자), 발표 대본 작성(슬라이드당 시간, 빈 노트만), 대본과 슬라이드 비교(핵심어 포함률·빠진 핵심어·예상 시간 + 생성형 제공자의 서술형 검토)
- **디자인**: 디자인 아이디어(템플릿·색·글꼴 조합 3개, 현재 슬라이드 미리 보기), 디자인 점검(12pt 미만 글자, 글 양, WCAG 명암 대비, 슬라이드 밖 개체, 텍스트 겹침, 글꼴 4종 이상, 빈 개체 틀, 어긋난 정렬, 제목 없음 → 고치기/모두 고치기), 구성 추천(슬라이드 나누기·2단 레이아웃·구역 머리글·차트 권장 → 적용)
- **이미지**: 이미지 생성 인터페이스(`ImageProvider`) — 설정하지 않으면 안내만 표시
- **키 보관**: API 키는 프레젠테이션·IndexedDB 문서에 넣지 않고 이 브라우저의 sessionStorage(기본) 또는 localStorage('키 기억')에만 둡니다. 서버가 없으므로 요청은 브라우저에서 제공자로 직접 갑니다.
- **중계 서버 보호**: 정해진 두 경로(`/v1/chat/completions`, `/v1/images/generations`)만 전달, 허용 사이트(Origin)·접근 코드·허용 모델 확인, 2MB 넘는 요청 거절, `/health`는 키 설정 여부만 응답
- **검증**: 실제 API 키가 없어 실제 GPT·Claude 호출은 하지 못했습니다. 중계 서버는 실제 Worker 코드를 단위 테스트와 E2E(브라우저 → Worker 코드 → 가짜 OpenAI)로 확인했습니다. 단위 테스트(가짜 fetch/SSE)와 E2E(가짜 API 응답)로 요청 형식·응답 처리·오류(401, 거절, 잘림)를 확인했습니다.

## 발표 도구 (11단계)

- **발표자 보기** (Alt+F5, 슬라이드 쇼 탭 › 발표자 보기): 현재 슬라이드(애니메이션·전환 그대로), 다음 슬라이드/다음 애니메이션 미리 보기, 노트(글자 크기 조절),
  발표 타이머(일시 중지·다시 시작), 현재 시각, 이전/다음, 도구 모음(펜·레이저, 모든 슬라이드, 확대, 검은 화면, 기타).
  **청중 화면 창**: 디스플레이 설정 › 청중 화면 창 열기 → 같은 상태를 공유하는 별도 창(React 포털)에 슬라이드만 표시, 보조 모니터로 옮겨 전체 화면.
  Chromium의 Window Management API가 있으면 "보조 모니터에 청중 화면 표시"로 다른 모니터 위치에 바로 열고, 모니터가 여러 대(`screen.isExtended`)이면 F5도 발표자 보기로 시작합니다.
- **포인터와 잉크**: 레이저 포인터(Ctrl+L, 쇼 설정의 색), 펜(Ctrl+P, 9색), 형광펜(Ctrl+I, 6색, 반투명), 지우개(Ctrl+E, 획 단위), 잉크 모두 지우기(E), 잉크 표시/숨기기(Ctrl+M),
  화살표 자동 숨기기/항상 표시/숨기기(Ctrl+U / Ctrl+A·A·= / Ctrl+H). 쇼를 끝낼 때 **잉크 주석 유지** → 자유형 도형(custGeom)으로 슬라이드에 추가(실행 취소 1번)
- **화면 확대**: 돋보기 → 영역 선택 후 클릭하면 2배, +/-로 1.5·2·3·4배, 확대한 화면 끌어서 이동, Esc로 원래대로. 확대하지 않은 상태에서 - 또는 G → **모든 슬라이드 보기**
- **오른쪽 클릭 메뉴**: 다음/이전, 모든 슬라이드, 확대, 포인터 옵션, 검은/흰 화면, 발표자 보기, 도움말(단축키 목록), 쇼 마침
- **기타 단축키**: H(다음 숨긴 슬라이드), S(자동 진행 중지/계속), 번호+Enter, Esc(확대 → 도구 → 쇼 순서로 해제). 전체 화면에서는 Keyboard Lock API로 Esc를 쇼가 직접 처리
- **예행 연습**: 슬라이드별 시간 측정 도구 모음(다음, 일시 중지, 반복, 총 시간) → 끝나면 "새 슬라이드 시간을 저장하시겠습니까?" → 슬라이드의 '다음 시간 후' 설정
- **녹화** (녹화 탭 / 슬라이드 쇼 탭): 마이크로 슬라이드마다 내레이션을 녹음(MediaRecorder → 16비트 PCM **WAV**로 변환, PowerPoint 호환)하고 시간도 기록.
  내레이션은 오른쪽 아래 오디오 개체(쇼 중 숨김·자동 재생)로 들어가며, 녹화 지우기(현재/모든 슬라이드의 시간·내레이션). **화면 녹화**(getDisplayMedia) → 현재 슬라이드에 비디오로 삽입
- **슬라이드 쇼 설정**: 보기 형식(발표자 진행·웹 형식(창)·대화형 자동 진행(키오스크: 클릭으로 넘기지 않음, 반복)), Esc까지 반복, 내레이션/애니메이션 없이, 펜·레이저 색,
  표시할 슬라이드(모두 / 시작~끝 / 재구성한 쇼), 화면 전환(수동 / 설정된 시간 사용), 발표자 보기 사용
- **재구성한 쇼**: 새로 만들기·편집(슬라이드 추가·순서·제거)·복사·제거·쇼 보기, 슬라이드 쇼 재구성 메뉴에서 바로 시작
- **PPTX**: `presProps.xml`의 `p:showPr`(loop·showNarration·showAnimation·useTimings, present/browse/kiosk, sldAll/sldRg/custShow, penClr, p14:laserClr),
  `presentation.xml`의 `p:custShowLst`, 자동 재생 미디어(`mediacall` playFrom + `p:audio/p:video` cMediaNode, showWhenStopped·반복)를 저장하고 다시 가져옵니다.
  pptxgenjs가 오디오도 `a:videoFile`로 기록하는 문제를 후처리에서 `a:audioFile`로 바로잡았습니다. LibreOffice로 변환해 재구성한 쇼·반복·자동 재생 명령이 인식되는지 확인했습니다.
- **제한**: 발표자 보기 사용 여부는 SlideLab 문서에만 저장(PowerPoint는 파일이 아닌 앱 설정), 잉크는 PowerPoint 잉크(InkML)가 아닌 자유형 도형으로 저장,
  녹화 중 카메라·잉크 재생 녹화와 비디오로 내보내기는 미지원(14단계), 키오스크의 5분 무입력 자동 재시작 미지원

## 전환·애니메이션 (10단계)

- **전환** (전환 탭): 없음·페이드·검정으로 페이드·밀어내기·닦아내기·분할·덮기·나타내기·원형·확대/축소·회전·뒤집기 12종, 효과 옵션(방향),
  기간, 모두 적용, 화면 전환 시기(마우스를 클릭할 때 / 다음 시간 후 자동), 미리 보기. 슬라이드 쇼에서 앞으로 넘어갈 때 재생
- **애니메이션** (애니메이션 탭): 나타내기 8종(나타내기·페이드·날아오기·떠오르기·닦아내기·분할·확대/축소·회전하며 나타내기),
  강조 5종(펄스·회전·크게/작게·흔들기·투명), 끝내기 7종, 이동 경로 7종(직선 4방향·대각선·호·원). 효과 옵션(방향), 애니메이션 추가(한 개체에 여러 효과),
  시작(클릭할 때/이전 효과와 함께/이전 효과 다음에), 재생 시간, 지연, 반복(다음 클릭까지 포함), 순서 바꾸기, 트리거(다른 개체 클릭 시)
- **애니메이션 창**: 단계 번호·종류 색·타이밍 표시, 다중 선택, 순서 이동, 삭제, 모두 재생, 트리거 묶음. 캔버스에 번호 배지와 이동 경로 표시
- **재생 엔진** (`engines/animation/`): 순수 함수 타임라인(`buildTimeline` → `frameStates`)이 PowerPoint 타이밍 의미(이전 효과와 함께 = 그룹 시작 + 지연)를 따르고,
  편집기 미리 보기와 슬라이드 쇼가 같은 엔진을 사용. 뒤로 가기/다음 클릭 시 진행 중인 단계 즉시 완료
- **PPTX**: 내보내기 시 `p:transition`(p14 확장 + 대체 콘텐츠)과 `p:timing`(mainSeq + interactiveSeq, presetID/Class/Subtype, 동작 요소)을 직접 생성.
  가져오기 시 같은 구조를 편집 가능한 애니메이션으로 해석하고, 바꾸지 않은 슬라이드는 원본 XML을 그대로 복원
- **제한**: 텍스트 문단 단위·그룹 내부 개체 대상 애니메이션은 원본 보존만(편집 불가), 곡선 이동 경로는 선분 근사,
  회전·뒤집기 전환은 p14 확장(구버전 앱은 페이드로 대체), 프리셋 ID는 가장 가까운 것을 사용(재생은 동작 요소 기준)

## 디자인·테마·슬라이드 마스터 (9단계)

- **테마 색/글꼴 토큰**: 색은 `@accent1`, `@accent1^0.6`(밝게), `@accent1~0.75`(어둡게), 글꼴은 `@heading`/`@body`로 저장할 수 있습니다.
  색 선택기의 테마 색 격자(기본 + 밝게/어둡게 5단계)와 새 개체·개체 틀·표 스타일·템플릿 장식이 토큰을 쓰므로, 테마·색 조합·글꼴 조합을 바꾸면 PowerPoint처럼 함께 바뀝니다.
  테마를 바꿀 때 현재 테마와 정확히 같은 고정 색/글꼴(가져온 PPTX, 이전 버전 문서)은 토큰으로 바뀌어 같이 따라갑니다. 내보낼 때는 실제 값으로 기록됩니다.
- **슬라이드 마스터 / 레이아웃** (`core/document/masters.ts`): 마스터(공통 디자인 + 제목/본문 개체 틀) → 레이아웃(디자인 + 개체 틀 배치) → 슬라이드(레이아웃 개체 틀을 복제, `ph`로 연결).
  마스터나 레이아웃을 고치면 **사용자가 따로 바꾸지 않은 위치·서식만** 하위에 전파되고, 한 번의 실행 취소로 함께 되돌아갑니다.
- **마스터 보기** (보기 › 슬라이드 마스터 또는 디자인 › 슬라이드 마스터): 마스터/레이아웃 목록, 같은 캔버스로 편집, 레이아웃 삽입·복제·삭제(사용 중이면 차단)·이름 바꾸기,
  개체 틀 삽입(제목/텍스트/날짜/바닥글/번호), 배경 그래픽 숨기기, 마스터/레이아웃별 배경
- **디자인 탭**: 테마 5종 + 사용자 지정 테마, 디자인 템플릿 6종(테마 + 마스터 장식 + 제목 레이아웃 디자인), 색 조합 14종, 글꼴 조합 10종, 테마 사용자 지정(색 10개·글꼴·이름 저장),
  현재 디자인을 내 템플릿으로 저장(파일 › 새로 만들기에서도 사용), 배경: 단색/그라데이션/무늬 12종/그림/투명도, 레이아웃 축소판이 있는 새 슬라이드 갤러리
- **무늬 채우기**: 도형·슬라이드 배경. PPTX에는 `a:pattFill`, 그라데이션 배경은 이미지가 아닌 `a:gradFill`로 저장
- **PPTX 가져오기**: 첫 마스터를 SlideLab 마스터로, 레이아웃 전체를 마스터 순서대로, 개체 틀을 `ph`로 연결해 가져옵니다.
  내보내기는 마스터·레이아웃 디자인을 각 슬라이드에 포함해 저장합니다(보이는 모양은 같고, 마스터 구조는 SlideLab 문서 안에서만 유지).

## 표·차트·미디어 (8단계)

- **표**: 삽입(격자 선택/대화 상자), 셀 클릭 편집(서식 있는 텍스트), Tab/Shift+Tab 셀 이동(마지막 셀에서 Tab → 행 추가), 드래그·Shift+클릭 셀 범위 선택,
  행/열 삽입·삭제, 셀 병합/분할, 테두리(모든/바깥/안쪽/개별, 펜 색·두께), 셀 음영, 가로·세로 맞춤, 행 높이/열 너비 같게, 표 스타일 5종 + 강조색·머리글/요약/줄무늬/첫째 열 옵션,
  내용에 맞춰 행 높이 자동 증가, 크기 조절 시 열/행 비례 조정
- **차트**: 세로/가로 막대(누적), 꺾은선, 영역, 원형, 도넛, 분산형 — 자체 SVG 렌더러, 스프레드시트형 데이터 편집기(Excel에서 복사한 표 붙여넣기), 종류 변경, 제목·범례(위치)·데이터 레이블, 계열 색, 글자 크기.
  PPTX로는 pptxgenjs의 **네이티브 차트(내장 Excel 포함)** 로 저장되어 PowerPoint에서 데이터 편집 가능
- **미디어**: 비디오(MP4/WebM)·오디오 삽입. 큰 파일은 IndexedDB `blobs`에 따로 저장(문서에는 참조만), 비디오 표지 자동 생성, 슬라이드 쇼 재생(자동 실행·반복 옵션), PPTX 내장 저장
- **링크**: 텍스트 범위 또는 개체에 하이퍼링크 (Ctrl+K), 슬라이드 쇼에서 클릭 시 열림, PPTX `hlinkClick`으로 저장/가져오기
- **아이콘**: Lucide 아이콘(ISC) 1,500여 개 검색·색 지정 후 SVG로 삽입 (지연 로딩)
- **가져온 표·차트·미디어**: 편집 가능한 개체로 변환하면서 원본 XML과 **내용 지문**을 보관 → 내용을 바꾸지 않으면 저장 시 원본 XML을 그대로 복원(완전 보존), 바꾸면 모델에서 새로 생성.
  표 스타일은 `tableStyles.xml` 정의를 해석해 셀 서식에 반영(정의가 없는 기본 제공 스타일은 '보통 스타일 2'로 근사). 방사형·3D·복합 차트, SmartArt, OLE는 계속 원본 보존 개체로 유지

## PPTX 호환성 (7단계)

**가져오기** (`src/services/import/`) — ZIP(Open XML) 패키지를 직접 해석합니다.
- 슬라이드 크기·순서·구역(p14:sectionLst)·숨김·노트, 테마 색(색 변형 lumMod/lumOff/tint/shade/alpha 포함)·글꼴(라틴/동아시아)
- 개체 틀 상속: 위치(슬라이드 → 레이아웃 → 마스터), 텍스트 서식(마스터 txStyles → 개체 틀 lstStyle → 문단 → 런), 본문 속성(맞춤·여백·세로쓰기·자동 맞춤)
- 문단/런: 맞춤, 수준, 글머리 기호(문자)/번호, 줄·문단 간격, 글꼴·크기·굵게·기울임·밑줄·취소선·색·강조, 줄 바꿈
- 도형: 프리셋 20종 + 근사(원래 프리셋 이름은 저장 시 유지), 사용자 지정 경로(custGeom: 직선·베지어·호), 채우기(단색·투명도·그라데이션·그림·스타일 참조), 선(색·두께·대시·화살표)
- 그림(자르기·투명도), 연결선, 그룹(중첩, 자식 좌표계), 슬라이드/레이아웃/마스터 배경, 마스터·레이아웃 디자인 개체(슬라이드 뒤에 표시)
- **편집하지 못하는 요소는 버리지 않습니다**: 표·차트·SmartArt·오디오/비디오·OLE·EMF 그림은 원본 XML을 그대로 보존하는 "보존된 개체"가 되어
  이동·크기 조절·삭제가 가능하고(표는 내용 미리 보기 표시), 전환·애니메이션 XML도 슬라이드에 보존됩니다.

**내보내기** (`src/services/export/`) — pptxgenjs로 생성한 뒤 `preserve.ts`가 후처리합니다.
- 보존된 개체를 원본 XML로 복원하고, 참조 파트(차트, 내장 Excel, SmartArt 데이터/그리기 캐시, 미디어)를 관계·콘텐츠 형식과 함께 재귀 복사
- 원래 도형 ID 복원 → 애니메이션 대상 유지 (대상이 삭제되면 해당 슬라이드 애니메이션만 제외하고 경고)
- 그라데이션 채우기, 그룹 구조(p:grpSp)를 XML에 직접 기록 (pptxgenjs 미지원 보완), 원본 테마·표 스타일 복원
- 원본 패키지는 IndexedDB(`packages`)에 보관되며 `.slidelab` 백업 파일에도 포함됩니다.

**알려진 제한** (가져오기 결과 대화 상자에 표시됨): 도형 효과(그림자·3D), 도형 조정 핸들 값, 꺾인 연결선 모양, 다중 경로 자유형의 경로별 채우기, 개체 틀 의미(저장 시 일반 텍스트 상자), 마스터 구조(디자인 요소는 각 슬라이드에 포함되어 저장). Strict Open XML과 이전 형식(.ppt)은 지원하지 않습니다.

**검증 방법**
- `scripts/make_fixtures.py`: python-pptx(독립 도구)로 표·차트·그룹·자른 그림·연결선·전환/애니메이션·구역이 든 테스트 파일 생성
- `src/services/import/__fixtures__/libreoffice.pptx`: LibreOffice가 작성한 PPTX (다른 XML 구조)
- 단위 테스트: 가져오기 해석, 왕복(가져오기 → 내보내기 → 다시 가져오기), 편집 후 저장(이동한 표 위치 반영, 삭제된 애니메이션 대상 처리)
- `REAL_PPTX_DIR=폴더 npx vitest run src/services/import/realFiles.test.ts`: 실제 PowerPoint로 만든 파일 일괄 왕복 검사
- 내보낸 파일은 python-pptx와 LibreOffice(`npm run verify:pptx`)로 다시 열어 확인

## 아키텍처

```
src/
  app/            App 셸, 부트스트랩(마지막 문서 복원 + 자동 저장 시작)
  types/          JSON 문서 모델 (Presentation → Slide → SlideObject)
  core/
    document/     팩토리(레이아웃·개체 생성), 조회, 스키마 마이그레이션
    commands/     commands.ts: 순수 문서 명령(immer draft) / actions.ts: UI 공용 고수준 동작
    history/      스냅샷 기반 실행 취소/다시 실행 (구조적 공유)
    store/        zustand 전역 상태 (문서, 선택, 보기, 제스처)
  editors/text/   모델↔DOM 변환(richText), contentEditable 편집기, 서식 엔진
  engines/rendering/  ObjectView/SlideView (캔버스·축소판·슬라이드 쇼 공용), 도형 기하
  components/     ribbon, sidebar, canvas, properties, statusbar, slideshow, dialogs, common
  services/       storage(IndexedDB, 자동 저장, 파일), import(PPTX 해석, 스크린샷), export(PPTX + 원본 보존 후처리)
  themes/  hooks/  utils/  styles/
```

- **좌표계**: 슬라이드 px(96 DPI). 16:9 = 1280×720 px = 13.333×7.5 in. 글꼴은 pt.
- **실행 취소**: 모든 변경은 `commit(label, recipe)` 하나 = 실행 취소 1단계. 드래그·텍스트 편집·슬라이더는 `beginGesture/updateGesture/endGesture`로 묶어 1단계로 기록.
- **렌더링**: 하나의 `SlideView`를 편집 캔버스, 축소판, 슬라이드 쇼, 새 문서 미리보기에서 공유해 화면이 일치.
- **텍스트**: 문단/런 모델과 동일한 DOM 구조를 편집기와 정적 렌더러가 공유하고, 편집 결과는 계산된 스타일로 다시 모델에 반영.
- **PPTX 원본 보존**: 미지원 요소는 `UnsupportedObject`(원본 XML + 원본 파트 경로)로, 전환/애니메이션은 `slide.source`로 보관.
